# Expense Tracker

A simple and responsive Expense Tracker built using **HTML, CSS, and JavaScript**.

This project allows users to add, manage, delete, and filter their daily expenses. Expense data is stored in **LocalStorage**, so the data remains available even after refreshing the page.

## Features

* Add new expenses
* Enter expense name and amount
* Select expense category
* Filter expenses by category
* Calculate total expenses automatically
* Delete expenses
* Save expenses using LocalStorage
* Responsive design for desktop, tablet, and mobile devices
* Display an empty-state message when there are no expenses

## Technologies Used

* HTML5
* CSS3
* JavaScript
* DOM Manipulation
* LocalStorage
* Array Methods (`filter`, `reduce`)
